# PvP Profile v1.0.15 Release Notes

**Release Date:** August 13, 2026
**Version:** 1.0.15
**Type:** Hotfix
**Compatibility:** Retail 12.1.0 / MoP Classic 5.5.4

## Overview

Fixes a packaging bug that caused the `LICENSE` file to ship with an invisible trailing space in its filename, making it impossible to open, rename, or delete on Windows.

## Changes

- Fixed a packaging bug where `.pkgmeta` had a stray trailing space in `license-output: LICENSE`, causing every release zip to ship a `LICENSE` file whose actual filename had an invisible trailing space
- On Windows, a filename with a trailing space can never be resolved by normal Explorer/`cmd`/PowerShell path lookups, so affected installs would show a `LICENSE` file that produced "item not found" errors on open/rename/delete and left the addon folder unable to be fully removed — even in Safe Mode, since this was a static filename issue, not caused by any running process
- New installs and updates from this version onward ship a correctly named `LICENSE` file
- Added a "Troubleshooting" entry to `README.md` with a PowerShell script that locates and removes any leftover ghost `LICENSE` file from installs affected by the packaging bug above
