# PvP Profile v1.0.17 Release Notes

**Release Date:** October 29, 2026
**Version:** 1.0.17
**Type:** Hotfix
**Compatibility:** Retail 12.1.5 / MoP Classic 5.5.4

## Overview

Fixes Lua errors that could appear when opening a player's right-click menu while the game hides that player's name from addons.

## Changes

- Fixed `attempt to perform numeric conversion on a secret number value (execution tainted by 'PvPProfile')` errors when opening party, raid, guild or other player right-click menus in PvP or instance situations where the game hides player names from addons
- In those situations, PvP Profile now leaves the menu untouched instead of adding its options

## Known Issues

None reported for this version.

## Support

If you encounter any issues with this release, please:
1. Check the [GitHub Issues](https://github.com/Kirom/PvP-Profile/issues) page
2. Ensure you're using the correct version for your WoW client (retail vs classic)
3. Try disabling other addons to check for conflicts
4. Check the [Discord](https://discord.gg/5sMTavfNsE)
